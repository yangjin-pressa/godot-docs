# VBoxContainer

**Inherits:** BoxContainer → Container → Control → CanvasItem → Node → Object

**Inherited By:** ColorPicker, FileSystemDock, ScriptEditorBase

---

## Description
A variant of BoxContainer that arranges its child controls vertically. Child controls are rearranged automatically when their minimum size changes.
