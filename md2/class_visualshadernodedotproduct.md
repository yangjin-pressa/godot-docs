**Class Name**: VisualShaderNodeDotProduct  
**Inherits**: VisualShaderNode → Resource → RefCounted → Object  

**Description**:  
Calculates a dot product of two vectors within the visual shader graph. Translates to `dot(a, b)` in the shader language.  

**Key Attributes**:  
- **Functionality**: Computes the dot product of two vectors.  
- **Shader Equivalent**: `dot(a, b)` in shader code.  
- **Purpose**: Used in visual shader graphs to perform vector operations.  

**Note**:  
This class is part of the Godot engine's visual shader system, allowing users to define mathematical operations in a graphical interface.
