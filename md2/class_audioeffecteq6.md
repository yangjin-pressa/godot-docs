# AudioEffectEQ6

**Inherits:**  
- AudioEffectEQ  
- AudioEffect  
- Resource  
- RefCounted  
- Object  

## Description  
- Band 1: 32 Hz  
- Band 2: 100 Hz  
- Band 3: 320 Hz  
- Band 4: 1000 Hz  
- Band 5: 3200 Hz  
- Band 6: 10000 Hz  

Each band allows modulation between -60 dB and +24 dB.
