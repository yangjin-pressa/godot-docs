# VisualShaderNodeRotationByAxis

**Inherits:** VisualShaderNode < Resource < RefCounted < Object

## Description
A visual shader node that modifies the rotation of the object using a rotation matrix. It can be used to rotate an object in an arbitrary axis.

## Key Features
- Applies rotation transformation using specified axis and angle (in radians)
- Works with mesh vertices for spatial transformation
- Part of visual shader node ecosystem for 3D graphics manipulation

## Usage Context
- Operates on 3D objects in 3D space
- Requires axis (vector) and angle (float) inputs
- Produces rotation matrix output for shader calculations
