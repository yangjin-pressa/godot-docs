# PlaceholderMaterial

**Inherits:** Material → Resource → RefCounted → Object

## Purpose
A placeholder class for materials used in specific scenarios:
- For dedicated server mode exports (only texture dimensions are retained)
- When a Material subclass is missing due to engine version differences
