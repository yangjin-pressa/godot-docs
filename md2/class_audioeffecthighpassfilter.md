# AudioEffectHighPassFilter

**Inherits:** AudioEffectFilter < AudioEffect < Resource < RefCounted < Object

## Description
Cuts frequencies lower than the AudioEffectFilter.cutoff_hz and allows higher frequencies to pass.

## Tutorials
- Audio buses

## Key Concepts
- **Function**: High-pass filtering to remove low frequencies.
- **Property**: AudioEffectFilter.cutoff_hz defines the frequency cutoff.
- **Use Case**: Audio buses processing.
