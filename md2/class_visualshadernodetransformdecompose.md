# VisualShaderNodeTransformDecompose

**Inherits:** VisualShaderNode < Resource < RefCounted < Object

## Description
Decomposes a Transform3D into four Vector3 values, one from each row of the matrix.

## Key Information
- **Functionality:** Breaks down a 4×4 transformation matrix into four 3D vectors (row vectors)
- **Output:** Four Vector3 instances representing matrix rows
- **Usage:** Used in visual shader graphs to extract transformation components
- **Inheritance Chain:** VisualShaderNode → Resource → RefCounted → Object
