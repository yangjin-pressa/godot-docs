The SkeletonIK3D class in Godot is used to apply inverse kinematics (IK) to a skeleton, allowing bones to animate to a target position. It is part of the physics2d module and is deprecated, suggesting it may be replaced by newer methods. The class is designed to work with a Skeleton3D node, enabling dynamic movement of bones in a chain to reach a specified target.

Key properties include `target`, which defines the target position for the tip bone, and `root_bone`, specifying the first bone in the IK chain. The `tip_bone` property identifies the last bone in the chain. Other properties, such as `use_magnet`, control whether a secondary target (magnet) is considered during calculations. The `target_node` property allows using a node's transform instead of a manual Transform3D value. The `override_tip_basis` property determines if the tip bone's rotation is overwritten by the target's rotation.

Methods like `start()` and `stop()` control whether IK effects are applied continuously or one-time. The `get_parent_skeleton()` method retrieves the parent Skeleton3D node when the class was added to the scene tree. Additional methods, such as `is_running()`, check the current state of the IK application.
