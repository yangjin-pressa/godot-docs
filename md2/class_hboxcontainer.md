**Class:** HBoxContainer  
**Inherits:** BoxContainer → Container → Control → CanvasItem → Node → Object  
**Inherited by:** EditorResourcePicker, EditorToaster, OpenXRInteractionProfileEditorBase  

**Description:**  
- A variant of BoxContainer that arranges child controls horizontally.  
- Child controls are rearranged automatically when their minimum size changes.
