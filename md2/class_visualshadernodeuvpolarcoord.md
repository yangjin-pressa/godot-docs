# VisualShaderNodeUVPolarCoord

**Inherits:** VisualShaderNode < Resource < RefCounted < Object

## Description
- Transforms UV values into polar coordinates
- Accepts parameters: scale, zoom strength, repeat
- Used to create swirl distortion effects

## Key Functionality
- Converts standard UV coordinates to polar coordinates
- Allows customization of transformation parameters
- Enables creation of radial pattern effects

## Technical Notes
- This node is part of the visual shader graph system
- Modifies texture coordinates for distortion effects
- Uses mathematical conversion between Cartesian and polar coordinates
