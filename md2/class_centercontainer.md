# CenterContainer

## Description
A container that keeps all of its child controls in its center at their minimum size.

## Tutorials
- [Using Containers](../tutorials/ui/gui_containers)

## Properties
- **use_top_left**: `false`  
  Determines if children are centered relative to the CenterContainer's top left corner.

## Property Descriptions
**use_top_left**  
Type: `bool`  
Default: `false`  
If `true`, centers children relative to the CenterContainer's top left corner.

## Methods
- `set_use_top_left(value: bool)`: Sets the use_top_left property.  
- `is_using_top_left()`: Returns the current value of use_top_left.
