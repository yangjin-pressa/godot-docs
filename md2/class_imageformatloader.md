# ImageFormatLoader

**Inherits:** RefCounted < Object  
**Inherited By:** ImageFormatLoaderExtension  

## Description  
The engine supports multiple image formats out of the box (PNG, SVG, JPEG, WebP, etc.), but you can add support for additional formats by extending `ImageFormatLoaderExtension`.
