# VisualShaderNodeParticleMultiplyByAxisAngle

**Inherits**: VisualShaderNode < Resource < RefCounted < Object

A visual shader helper node for multiplying a particle's position vector by rotation using a specific axis. Intended for use with emitters.

## Properties
- **degrees_mode**: bool = true  
  Indicates whether the angle is interpreted in degrees (true) or radians (false).

## Method Descriptions
- **set_degrees_mode(value: bool)**  
  Sets the degrees_mode property.  
- **is_degrees_mode()**: bool  
  Returns the current value of degrees_mode.
