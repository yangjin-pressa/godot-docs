## Description  
- **Purpose:** Unpacks the screen normal texture in World Space.  
- **Use case:** Creates outline effects.  

## Key Features  
- **Functionality:** Extracts screen space normal data for 3D effects.  
- **Node type:** Visual shader node for graphics processing.
