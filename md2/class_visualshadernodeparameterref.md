# VisualShaderNodeParameterRef

**Inherits:** VisualShaderNode → Resource → RefCounted → Object

## Description
Creating a reference to a VisualShaderNodeParameter allows you to reuse this parameter in different shaders or shader stages easily.

## Properties
- **parameter_name** (String) = "[None]"

## Property Descriptions
- **parameter_name**: The name of the parameter which this reference points to.
  - **set_parameter_name**: Sets the parameter name.
  - **get_parameter_name**: Retrieves the parameter name.
