# VSplitContainer

**Inherits:**  
- SplitContainer  
- Container  
- Control  
- CanvasItem  
- Node  
- Object  

## Description  
- A container that accepts only two child controls, then arranges them vertically and creates a divisor between them.  
- The divisor can be dragged around to change the size relation between the child controls.
