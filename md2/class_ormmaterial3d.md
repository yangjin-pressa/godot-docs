ORMMaterial3D  
- **Inherits**: BaseMaterial3D, Material, Resource, RefCounted, Object  
- **Description**: A PBR material using an ORM texture for ambient occlusion, roughness, and metallic maps. Unlike StandardMaterial3D, it combines these properties into a single texture.  
- **Tutorials**: [Standard Material 3D and ORM Material 3D](../tutorials/3d/standard_material_3d)
