**MultiMeshInstance3D**  
A node used to instantiate a `MultiMesh`, optimized for rendering multiple instances efficiently.  

**Inherits From**  
`GeometryInstance3D` → `VisualInstance3D` → `Node`  

---

### **Description**  
The `MultiMeshInstance3D` is a node that allows for the instantiation of a `MultiMesh`, making it ideal for efficiently rendering large numbers of objects that share common geometry.
