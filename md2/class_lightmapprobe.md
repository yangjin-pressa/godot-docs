# LightmapProbe

**Inherits:** Node3D < Node < Object

## Description

Represents a manually placed probe for dynamic object lighting with LightmapGI. LightmapProbe affects the lighting of GeometryInstance3D-derived nodes with GI_MODE_DYNAMIC set.

Key features:
- Probes are used to enhance dynamic lighting in specific areas
- Automatically generated by LightmapGI when generate_probes_subdiv is not set to GENERATE_PROBES_DISABLED
- Manual placement allows for more detailed lighting in specific regions
- Probes placed after baking lightmaps are ignored

Important note:
Probes must be baked again after creation or modification to take effect. Nodes placed after baking are not recognized by dynamic objects.
