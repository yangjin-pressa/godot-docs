# SpringBoneCollisionCapsule3D

**Inherits:** SpringBoneCollision3D → Node3D → Node → Object

## Description
A capsule shape collision that interacts with SpringBoneSimulator3D.

## Properties
- **height**: float, default 0.5  
  The capsule's height.
- **inside**: bool, default false  
  If true, the collision acts to trap the joint within the collision.
- **radius**: float, default 0.1  
  The capsule's radius.

## Methods
- **set_height(value: float)**  
  Sets the capsule's height.
- **get_height()**  
  Returns the capsule's height.
- **set_inside(value: bool)**  
  Sets whether the collision traps the joint.
- **is_inside()**  
  Checks if the collision traps the joint.
- **set_radius(value: float)**  
  Sets the capsule's radius.
- **get_radius()**  
  Returns the capsule's radius.
