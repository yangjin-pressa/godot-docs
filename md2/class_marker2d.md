**Class Name**: Marker2D  
**Inherits**: Node2D → CanvasItem → Node → Object  

---

### **Description**  
A generic 2D position hint for editing. Similar to Node2D but always displays as a cross in the 2D editor. The cross's visual size can be adjusted via the editor's gizmo when the node is selected.  

---

### **Properties**  
- **gizmo_extents**: `float` = `10.0`  
  - **Description**: Size of the gizmo cross in the editor.  

---

### **Methods**  
- **set_gizmo_extents(value: float)**  
  - **Description**: Sets the size of the gizmo cross.  

- **get_gizmo_extents()**  
  - **Description**: Returns the current size of the gizmo cross.
