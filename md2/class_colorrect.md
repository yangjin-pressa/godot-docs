# ColorRect

**Inherits:** Control < CanvasItem < Node < Object

A control that displays a solid color rectangle.

## Description
Displays a rectangle filled with a solid color. If you need to display the border alone, consider using a Panel instead.

## Tutorials
- [2D Dodge The Creeps Demo](https://godotengine.org/asset-library/asset/2712)

## Properties
- color: Color = Color(1, 1, 1, 1)

## Property Descriptions
**color** (Color) = Color(1, 1, 1, 1)

- `set_color(value: Color)`: Sets the fill color.
- `get_color()`: Returns the fill color.

**Note:** This method is virtual (overrideable) and const (no side effects).
