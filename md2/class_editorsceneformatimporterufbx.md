# EditorSceneFormatImporterUFBX

**Experimental:** This class may be changed or removed in future versions.

**Inherits:** EditorSceneFormatImporter < RefCounted < Object

## Description
- Designed to load FBX files and supports both binary and ASCII FBX files from version 3000 onward
- Supports various 3D object types: meshes, skins, blend shapes, materials, and rigging information
- Aims for feature parity with the official FBX SDK and supports FBX 7.4 specifications
