**Class Name**: VisualShaderNodeParticleSphereEmitter  
**Inherits**: VisualShaderNodeParticleEmitter < VisualShaderNode < Resource < RefCounted < Object  

**Description**:  
A visual shader node that makes particles emitted in a sphere shape.  

**Key Features**:  
- Emits particles in a spherical pattern.  
- Requires specification of **inner** and **outer radii** for the sphere.
