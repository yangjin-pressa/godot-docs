# Marker3D

**Inherits:** Node3D < Node < Object

Generic 3D position hint for editing. It's just like a plain Node3D, but it displays as a cross in the 3D editor at all times.

## Description

Generic 3D position hint for editing. It's just like a plain Node3D, but it displays as a cross in the 3D editor at all times.

## Properties

- **gizmo_extents**: float = 0.25  
  Size of the gizmo cross that appears in the editor.

## Property Descriptions

### gizmo_extents
**Type**: float  
**Default**: 0.25  
**Description**: Size of the gizmo cross that appears in the editor.

## Method Definitions

- `set_gizmo_extents(value: float)`: void  
- `get_gizmo_extents()`: float  

## Notes
- These methods are used to manipulate the gizmo cross size in the 3D editor.
