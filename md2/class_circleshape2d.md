# CircleShape2D

## Inheritance
- Shape2D
- Resource
- RefCounted
- Object

## Description
A 2D circle shape used for physics collision. Usually used to provide a shape for a CollisionShape2D.

## Performance
- CircleShape2D is fast to check collisions against. It is faster than RectangleShape2D and CapsuleShape2D.
