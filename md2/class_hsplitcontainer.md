# HSplitContainer

**Inherits:**  
- SplitContainer  
- Container  
- Control  
- CanvasItem  
- Node  
- Object  

## Description  
A container that accepts only two child controls, then arranges them horizontally and creates a divisor between them. The divisor can be dragged around to change the size relation between the child controls.  

## Tutorials  
- Using Containers (see ../tutorials/ui/gui_containers)  

## Key Features  
- Splits two child controls horizontally  
- Provides a draggable grabber to adjust split ratio  
- Inherits from `SplitContainer` and `Container` classes  
- Designed for UI layout with two proportional child elements
