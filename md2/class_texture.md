# Texture

- **Description**: Texture is the base class for all texture types. Common texture types are Texture2D and ImageTexture. See also Image.  
- **Inherits**: Resource < RefCounted < Object  
- **Inherited By**: Texture2D, Texture3D, TextureLayered  

**Key Attributes**:  
- Base class for all texture types  
- Supports Texture2D, Texture3D, TextureLayered subclasses  
- Inherits from Resource, RefCounted, and Object  

**Related Classes**:  
- Texture2D  
- ImageTexture  
- Image  

**Note**: This class defines the common interface for texture resources in the Godot engine.
