# HSlider

**Inherits**: Slider < Range < Control < CanvasItem < Node < Object

A horizontal slider that goes from left (min) to right (max).

## Description
- A horizontal slider, used to adjust a value by moving a grabber along a horizontal axis.
- It is a Range-based control and goes from left (min) to right (max).
