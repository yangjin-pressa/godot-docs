# XRControllerTracker

## Class Hierarchy
- Inherits: XRPositionalTracker < XRTracker < RefCounted < Object

## Description
A tracked controller that is added to the XRServer's active tracking list when detected by the XRInterface. This class is consumed by XRController3D for 3D controller functionality.
