# AudioEffectEQ21

**Inherits:** AudioEffectEQ < AudioEffect < Resource < RefCounted < Object

## Description
Adds a 21-band equalizer to an Audio bus, controlling frequencies from 22 Hz to 22000 Hz. Each band can be modulated between -60/+24 dB.

## Frequency Bands
1. 22 Hz  
2. 32 Hz  
3. 44 Hz  
4. 63 Hz  
5. 90 Hz

16. 4000 Hz  
17. 5600 Hz  
18. 8000 Hz  
19. 11000 Hz  
20. 16000 Hz
