# VisualShaderNodeVectorFunc

## Class Hierarchy
```plaintext
public class VisualShaderNodeVectorFunc : VisualShaderNode
```

## Description
A node that performs a vector function operation based on the selected function.

## Properties
- **function**: 0  
  The function to be performed. See `Function` for options.
