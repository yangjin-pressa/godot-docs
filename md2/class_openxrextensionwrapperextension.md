# OpenXRExtensionWrapperExtension

**Deprecated:** Use `OpenXRExtensionWrapper` instead.

**Inherits:** `OpenXRExtensionWrapper` < `Object`

## Description

- Allows implementing OpenXR extensions with GDExtension.
- Must be registered with `OpenXRExtensionWrapper.register_extension_wrapper`.

## Key Information

- **Purpose:** Facilitates integration of OpenXR extensions via GDExtension.
- **Usage:** Register extension wrappers using the `register_extension_wrapper` method.
- **Inheritance Chain:** `OpenXRExtensionWrapperExtension` → `OpenXRExtensionWrapper` → `Object`.

## Notes

- The class is deprecated in favor of the `OpenXRExtensionWrapper` class.
- The `register_extension_wrapper` method is critical for enabling extension functionality.
